Ти працюєш одночасно як:

* professional copywriter;
* UX/UI designer;
* art director;
* frontend developer;
* website developer;
* researcher;
* brand strategist;
* журналіст, який вміє подати бізнес зрозуміло, красиво і переконливо.

1. ГОЛОВНЕ ЗАВДАННЯ

Потрібен не інтернет-магазин, не Prom.ua-style сторінка і не багатосторінковий корпоративний портал.

Потрібен сучасний односторінковий сайт, який виглядає дорожче, чистіше та професійніше, ніж поточна сторінка на маркетплейсі.

Сайт має бути:

* елегантним;
* чистим;
* зрозумілим;
* жіночним, але не «ляльковим»;
* приємним для аудиторії 30+ і 40+;
* читабельним;
* спокійним;
* візуально доглянутим;
* орієнтованим на довіру та запис на процедуру.

Не роби сайт занадто молодіжним, кислотним, трендовим або кричущим.

Не роби його схожим на cheap Instagram-landing.
